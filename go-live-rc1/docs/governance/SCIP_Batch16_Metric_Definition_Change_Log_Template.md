# SCIP Batch 16 Metric-Definition Change Log Template

| Field | Required content |
|---|---|
| Metric key | Stable internal metric ID |
| Current definition | Existing business definition |
| Proposed definition | New definition and reason |
| Source reports | R-series source lineage |
| Reporting basis | Finance, MDO, R08, R36, mixed, or hidden |
| Validation rule | Tolerance, reconciliation, and smoke test |
| Approver | Data owner / Finance / MIS as applicable |
| Rollout gate | dev, staging, pilot, UAT, production |
| Rollback criteria | Condition that restores prior definition |

No metric wording change may ship without source lineage and reporting-basis language.
