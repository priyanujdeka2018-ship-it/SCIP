- [ ] stale critical source.
- [ ] missing critical lineage.
- [ ] migration failure.
- [ ] backup failure.
- [ ] high RBAC denial rate.
- [ ] slow endpoint p95.
- [ ] failed audit export.

- [ ] cache invalidation failure.
