# SCIP Batch 16 Change-Control Board Charter

## Purpose
Protect trust in SCIP by controlling changes to metrics, sources, Quickball explanations, role visibility, workflow states, and Liquid Glass navigation.

## Hard blocks
- Adds a third Arrival door.
- Reintroduces Entity Head role.
- Weakens no-silent-fallback.
- Moves business computation into frontend.
- Displays financial truth on heavy glass/blur surfaces.
- Allows critical metrics without lineage.
- Allows account actions without owner/entity/amount-ageing validation.

## Required decision fields
- Item ID
- Evidence hash
- Decision owner
- Rationale
- Rollout gate
- Rollback criteria
- Release note requirement
