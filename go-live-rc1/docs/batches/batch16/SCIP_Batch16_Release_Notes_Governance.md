# SCIP Batch 16 Release-Notes Governance

## Required sections
1. What changed
2. Why it changed
3. Evidence used
4. Roles affected
5. Metric/source/lineage impact
6. User-facing Liquid Glass impact
7. Rollout gate
8. Rollback criteria
9. Signoff owners

## Language rule
Use human product language in release notes. Avoid exposing raw implementation labels unless the audience is MIS/QCG/Admin or engineering.
