# SCIP Batch 17 — Ownership Map

| Area | Owner | Accountability |
|---|---|---|
| Executive sponsorship | Board/CXO sponsor | Approve strategic outcomes, roadmap gates, and benefit realization. |
| Collections operating rhythm | CCO/GM/AGM | Own action queue adoption, escalation cadence, workflow closure, and intervention outcomes. |
| Financial truth and target basis | Finance | Own Finance/MDO reconciliation, target basis approvals, PR/SOA exception process, audit exports. |
| Source governance and platform administration | MIS/QCG/Admin | Own source freshness, adapters, lineage, RBAC provisioning checks, migrations, release governance. |
| Collector execution | Collector/RM managers | Own action disposition quality, PTP follow-up, queue feedback, and closure evidence. |
| Identity and security | IT/Security | Own SSO/JWT, user provisioning, RBAC policy enforcement, denied-attempt audit review. |
| Data engineering and warehouse alignment | Data Engineering | Own DW blueprint, pipeline reconciliation, source-system parallel run, and cutover readiness. |
