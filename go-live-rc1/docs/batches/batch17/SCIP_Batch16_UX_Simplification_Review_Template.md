# SCIP Batch 16 UX Simplification Review Template

## Review rule
Each improvement must preserve: two doors, three or fewer choices, one question per screen, evidence on demand, and solid financial truth surfaces.

## Fields
- World: Live Pulse or Narratives
- Focus
- Friction evidence
- Proposed simplification
- Choices before/after
- Evidence depth impact
- Expected adoption impact
- Rollback criteria

Do not add permanent rails, raw section trees, or dashboard-first observability at Arrival.
