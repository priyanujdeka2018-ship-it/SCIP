# SCIP Batch 17 — Executive Operating Rhythm Templates

## Weekly management review template
1. What changed this week?
2. Which risk/action queues need intervention?
3. Which workflows are stale, overdue, or blocked?
4. Which notifications are effective or noisy?
5. Which owners need escalation?
6. What decision is needed before next week?

## Monthly optimization review template
1. Adoption and engagement signal.
2. Source freshness and lineage exceptions.
3. Quickball answer-quality sample.
4. UX simplification review.
5. Backlog prioritization using Batch 16 scoring model.
6. Release train approval / hold / rollback.

## Quarterly executive steering template
1. Strategic outcome progress.
2. Benefits realization.
3. Major roadmap items and decisions.
4. Risks, dependencies, and unresolved escalations.
5. Next-quarter OKRs and release train.
6. Executive signoff.
