# SCIP Batch 14 Executive Acceptance Criteria

## Product acceptance

- [ ] Arrival is calm and shows only Live Pulse and Narratives.
- [ ] SCIP feels like an intelligent briefing, not a dashboard control panel.
- [ ] Live Pulse answers what needs attention now.
- [ ] Narratives tells the board-level story behind the numbers.
- [ ] Evidence is available on demand.
- [ ] Dense financial truth uses solid surfaces.
- [ ] Quickball explains numbers with lineage and does not hallucinate.

## Trust acceptance

- [ ] Every critical number has source file, sheet/range/cell, validation, confidence, reporting basis.
- [ ] No silent fallback appears in executive or operational views.
- [ ] Data-confidence state is visible after entry.
- [ ] Audit export proves the lineage chain.

## Control acceptance

- [ ] SSO/JWT actor identity works.
- [ ] RBAC row-level visibility works.
- [ ] Workflows can be assigned, dispositioned, escalated, and closed.
- [ ] Notifications are deduped/suppressed correctly.
- [ ] Denied attempts are audit-logged.

## Rollout acceptance

- [ ] UAT role scripts pass.
- [ ] Rollback tested.
- [ ] Break-glass tested.
- [ ] Production smoke passed.
- [ ] Executive signoff recorded.
