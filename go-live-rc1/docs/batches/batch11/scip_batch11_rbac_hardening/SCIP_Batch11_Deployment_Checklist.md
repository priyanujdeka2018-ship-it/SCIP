# SCIP Batch 11 Production Deployment Checklist

## Environment

Set these environment variables:

```bash
SCIP_ENV=production
FRONTEND_URL=https://<frontend-domain>
BACKEND_URL=https://<backend-domain>
CORS_ALLOWED_ORIGINS=https://<frontend-domain>
SCIP_AUTH_MODE=sso-jwt
SCIP_SECRET_KEY=<secret-from-vault>
SCIP_AUDIT_DB=/data/scip_audit.sqlite
SCIP_BACKUP_DIR=/data/backups
```

## Security

- Replace patch-pack header trust with SSO/JWT verification.
- Ensure identity gateway sets the same actor contract.
- Remove wildcard CORS.
- Keep secrets in a secret manager, not source control.
- Confirm Entity Head cannot authenticate.
- Confirm denied attempts are logged.

## Database

- Run `POST /deployment/migrate` as MIS/QCG/Admin.
- Confirm migration checksums.
- Run `POST /deployment/backup-check`.
- Confirm audit exports can be generated by MIS/QCG/Admin.

## Role verification

- Board/CXO sees only command, forecast, digest/audit summary outputs.
- CCO/GM/AGM sees management and collector escalations.
- Finance sees finance queues and finance audit rows.
- MIS/QCG/Admin sees governance, deployment, audit and admin outputs.
- Collector/RM sees own actions only.

## Frontend

- Ensure `VITE_BACKEND_URL` points to production backend.
- Run full Vite build.
- Validate Arrival still has only Live Pulse and Narratives.
- Validate security posture bar renders after entry.
- Validate no financial computation moved into frontend.
